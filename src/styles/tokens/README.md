# 디자인 토큰 — 디자이너 산출물을 받는 자리

> 상태: **비어 있음.** 고객사 인하우스 디자이너의 산출물을 기다린다.
> 관련 질문: `docs/CLIENT_QUESTIONS.md` **E-2**(디자인 시스템 토큰 제공 여부)

## 왜 비어 있는가

디자인은 고객사 인하우스 디자이너가 담당한다. 여기에 임의로 색·간격·폰트를 정해 넣으면
나중에 실제 시안이 왔을 때 두 개의 진실이 생기고, 어느 쪽이 맞는지 아무도 모르게 된다.
그래서 **구조만 만들고 값은 비워 둔다.**

## 파일 구성

| 파일 | 담을 것 |
| --- | --- |
| `colors.css` | 브랜드 컬러, 텍스트/배경, 상태색(품절·에러) |
| `typography.css` | 폰트 패밀리, 크기 스케일, 행간, 자간 |
| `spacing.css` | 간격 스케일, 컨테이너 최대폭, 브레이크포인트 |

## 쓰는 방법 (Tailwind 4)

Tailwind 4 는 `tailwind.config.js` 가 아니라 **CSS 안에서** 설정한다.
`src/app/globals.css` 가 이 파일들을 import 하고, `@theme` 블록이 CSS 변수를
Tailwind 유틸리티 클래스로 바꿔준다.

```css
/* globals.css */
@import "tailwindcss";
@import "../styles/tokens/colors.css";

@theme inline {
  --color-brand: var(--brand);   /* → bg-brand, text-brand 로 쓸 수 있게 된다 */
}
```

## 디자이너에게 요청할 것

값을 받을 때 아래 형태로 오면 그대로 옮길 수 있다.

- **컬러**: 이름 + HEX. 이름은 역할로 (`brand-primary`, `text-muted`).
  `blue-500` 처럼 색 자체를 이름으로 쓰면 나중에 브랜드 컬러가 바뀔 때 전부 틀린 이름이 된다.
- **타이포**: 폰트명 + **웹 사용 라이선스 유무**.
  유료 폰트를 웹에 올리면 별도 라이선스가 필요하다 — 나중에 발견하면 교체 비용이 크다.
- **간격**: 4px 또는 8px 배수 스케일이면 가장 단순하다.
- **브레이크포인트**: 모바일·데스크톱 기준 너비 (E-3 질문)

## 현재 임시로 쓰고 있는 것

`create-next-app` 기본값이 그대로 남아 있다. **브랜드 디자인이 아니다.**

- 폰트: Geist / Geist Mono (Google Fonts, 오픈소스 라이선스라 임시 사용에 문제 없음)
- 색: 흑/백 + 시스템 다크모드

시안이 오면 전부 교체한다.
